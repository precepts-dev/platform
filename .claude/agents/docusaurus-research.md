## Key files

- `packages/site/sidebars.ts` — sidebar definitions (autogenerated from filesystem)
- `packages/site/src/css/custom.css` — theme customizations (warm paper + sage palette)
- `packages/site/src/theme/` — swizzled components (DocItem/Content for frontmatter metadata bar)
- `packages/site/scripts/sync-standards.ts` — syncs standards from @precepts/standards into docs/

- `packages/site/docs/` — build artifact (gitignored), populated by sync script

## Project context

- Docusaurus with classic preset, no blog (version detected above)
- `onBrokenLinks: 'throw'` — build fails on broken links
- Content comes from `@precepts/standards` npm package, synced at build time
- Sidebar categories and landing pages are owned by the platform repo in `docs-meta/`
- Custom `sidebarItemsGenerator` ensures doc items sort before category items
- Fonts: DM Sans (body) + JetBrains Mono (code) via Google Fonts
- Search: `@easyops-cn/docusaurus-search-local`
